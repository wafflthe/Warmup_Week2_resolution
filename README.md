# Contact list cli app

simple Cli app to store contacts names and emails

Commands:
-a/--add {Name} {Email} Adds a new contact to your list with the specified name and email
-l/--list Shows the current people added to your contacts along with an index number for each person
-d/--delete {Contact index number} lets you delete someone from your contacts by index number (displayed in -l)
-i/--info displays info about the app
